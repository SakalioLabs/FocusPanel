# FocusPanel 0.10.98

这一版删除重复的 Focus 中心中转层，让核心工作区真正一次可达。

- 紧凑栏“工作”按钮普通点击直接打开最近使用的工作区，不再先弹出另一个中心。
- 展开后顶部持续显示概览、桌面收纳、任务、番茄钟、AI 和设置六个一级入口。
- 右键菜单保留最近工作区和全部模块直达，今日概览不会因删除中转层而失去入口。
- 删除 Focus 中心的重复模块按钮、最近使用按钮、更新卡片和状态机，减少同一功能多套入口。
- 更新提示点继续显示在“工作”入口；进入工作区后可直接点击顶部设置完成更新。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
