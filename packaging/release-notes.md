# FocusPanel 0.9.43

- 普通设置从安装目录迁移到 `%APPDATA%\FocusPanel\settings.json`，安装版升级后不再受只读目录或版本切换影响。
- 首次运行自动读取旧版 `settings.json` 并复制到新位置，保留旧文件作为回退，不删除用户配置。
- 设置保存改为同目录临时文件加原子替换；读写失败可诊断，不再静默丢失。
- 旧版默认图片目录会安全迁移到 `%APPDATA%\FocusPanel\Images`，用户自定义目录保持不变。
- 删除已永久停用的全屏桌面覆盖 ViewModel 和 Smart Rescue 旧流程，继续保留侧边栏桌面收纳。
- 清理模型、图标加载、文件监测与只读转换器的空值边界，应用项目达到 0 警告、0 错误。
- 新增设置迁移、原子保存、错误恢复、中文日期分组和转换器回写保护测试；不隐藏真实任务栏，不修改当前安装实例。
