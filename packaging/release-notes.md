# FocusPanel 0.11.0

这一版恢复任务栏用户最熟悉的开始按钮语义，不再用自制开始中心替代 Windows 开始菜单。

- 左键或 Enter 直接打开 Windows 原生开始菜单，不再要求 Shift 组合键。
- 右键或 Shift+F10 继续打开完整 Win+X 风格系统管理菜单。
- 删除重复展示固定应用、系统工具和“全部应用”的 FocusPanel 开始中心。
- 虚拟桌面的上一个、新建、下一个和关闭迁入右键菜单，关闭仍需二次确认。
- 固定与运行应用继续由统一应用栏呈现，全部应用继续由统一搜索提供。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
