# FocusPanel 0.11.61

- 状态中心明确提供 Panel 自有“后台应用与窗口”，不调用 Windows 任务栏或隐藏图标抽屉。
- 可识别的固定、运行、后台和仅消息窗口应用继续在同一列表中启动、切换和管理。
- 收纳前检测到的独立 `.ico` 会复制进 FocusPanel 图标库，源图标之后移动或隐藏也不丢失。
- 自定义图标按完整路径和稳定文件身份绑定，同名桌面项目不会串记录。
- 图标模式改为固定 12px 节奏的密排换行，消除一行一个和随机大空隙；列表模式继续回收虚拟化。

升级前仍会恢复原生任务栏；现有 SQLite 数据、桌面文件路径、自定义分区和用户设置不会被删除。
