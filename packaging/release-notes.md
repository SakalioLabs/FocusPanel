# FocusPanel 0.11.3

这一版让紧凑栏系统状态从泛化标签变成可以直接读取的真实音量。

- 音频正常时直接显示 `45%` 一类实际音量，不必打开状态中心或等待工具提示。
- 静音时明确显示“静音”，没有默认输出设备时显示“不可用”。
- 图标、文本、读屏和静音按钮继续共用同一个音频状态模型，不会出现互相矛盾的两套值。
- 鼠标移到状态入口时通过既有合并刷新队列读取一次系统状态，外部音量变化不会长期残留旧值。
- Panel 隐藏时仍不轮询音频；滚轮调音量、右键静音、中键播放暂停和普通点击语义保持不变。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
