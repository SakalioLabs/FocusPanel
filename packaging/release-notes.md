# FocusPanel 0.11.16

- 修复 Windows 原生任务栏开启自动隐藏后，底部悬停重新出现且 FocusPanel 显示“已安全恢复”的问题。
- 空窗口区域、DWM cloak 或窗口隐藏任一仍有效时继续接管，不再因单层瞬时失效误退出。
- 只有全部抑制层失效且原生任务栏实际重新出现时才执行安全恢复，不循环隐藏、不反复写工作区。
- 自动隐藏任务栏的遗留恢复会话可正确完成并清除，不再让后续启动反复处理过期状态。
- 智能分区同时升级为现有布局上下文规划，支持聊天偏好、置信度、理由、快捷方式语义和超过 80 项的分批处理。

升级前仍会恢复原生任务栏；现有 SQLite 数据、桌面文件路径、自定义分区和用户设置不会被删除。
