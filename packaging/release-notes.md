# FocusPanel 0.9.92

- 文件监控、手动刷新和自动整理后的完整刷新统一经过同一个串行闸门，不再同时修改桌面文件集合。
- 监控线程在已持有刷新闸门时调用内部刷新核心，避免递归等待自身；公开刷新入口仍对所有外部调用串行。
- 收纳和取消收纳共享独立的文件属性操作闸门，多次拖放、自动整理与拖出恢复不会并发改写同一项目属性和恢复记录。
- Panel 退出后，等待中的自动整理与属性操作会在真正开始前停止；已完成磁盘操作的迟到界面回调不会再修改已释放集合。
- Dispatcher 关闭期间不再排入桌面集合更新，所有属性操作的内存同步统一回到 UI Dispatcher。
- Release 构建 0 错误、0 警告，全量 533 项测试和界面冒烟通过。
