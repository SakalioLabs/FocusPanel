# FocusPanel 0.11.55

- 删除 FocusPanel 自己的任务栏托盘图标；普通关闭折回紧凑栏，右缘和全局快捷键继续可用。
- 状态中心只打开 Panel 自有后台应用与窗口总览，不触发 Windows“显示隐藏图标”抽屉。
- 自定义 `.ico` 复制到 FocusPanel 图标库并按路径/文件标识准确绑定，收纳或同名项目不再导致串图标。
- 收纳图标网格采用真实视口宽度和固定 12px 间距，修复偶发一行一个与空隙异常。
- 显示桌面改用 Windows Shell 公开接口，不再模拟 `Win+D`。

升级前仍会恢复原生任务栏；现有 SQLite 数据、桌面文件路径、自定义分区和用户设置不会被删除。
