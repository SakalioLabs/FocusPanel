# FocusPanel 0.11.1

这一版把产品最常用的两个工作区放回紧凑栏一级入口，不再让用户先猜“工作”按钮是什么意思。

- “桌面收纳”和“任务”成为两个始终可见的一键入口，普通左键或 Enter 直接展开对应工作区。
- 删除含义模糊的“工作”中转按钮及其右键模块菜单，减少一次选择和一套隐藏手势。
- 任务入口直接显示未完成任务数，超过 99 项稳定显示 `99+`，读屏同步播报数量。
- 收纳与任务入口用左侧状态线显示最近打开的主工作区，收回 Panel 后仍能看出返回位置。
- 概览、番茄钟、AI 和设置继续位于展开工作区顶部的一级导航，没有删除功能。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
