# FocusPanel 0.10.80

这一版提供不依赖原生任务栏的 FocusPanel 开始中心。

- 普通点击开始按钮直接打开固定应用与常用系统入口，避免原生开始菜单失效时按钮无反应。
- 可直接打开资源管理器、设置、终端、任务管理器或进入全部应用搜索。
- Shift+点击保留 Windows 原生开始菜单，右键保留完整 Win+X 菜单。
- 第二次点击开始按钮只关闭开始中心，不收回整个 Panel；`Esc` 与其他弹层互斥语义保持一致。
- 固定应用复用统一任务栏身份和排序，不建立重复数据。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
