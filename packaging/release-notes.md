# FocusPanel 0.10.78

这一版把桌面收纳恢复改为自动、无阻塞流程，并彻底隔离已收纳图标的分区切换与文件属性操作。

- 首次启动 0.10.78 自动恢复旧版闪退可能遗留的桌面图标，无需寻找修复按钮。
- 恢复通知改为非阻塞 Toast，不再用模态对话框挡住应用启动。
- 已收纳卡片换分区只修改数据库分类，不重新写隐藏属性、不刷新 Explorer、不请求管理员权限。
- 数据库提交失败会保留原分区和卡片，异常由当前交互吸收，不结束 Panel。
- 手动紧急恢复仅保留为权限异常或损坏记录的最后保险。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
