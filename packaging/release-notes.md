# FocusPanel 0.10.97

这一版把首次启动从“先隐藏系统任务栏”改成“先正常体验，再自行决定是否接管”。

- 首次引导默认按钮是“开始使用（保留任务栏）”，不会在用户尚未体验时先改变 Windows 壳层。
- “立即接管任务栏”仍清楚可选，后续也可从设置随时启用。
- 引导只在用户尚未作出首次决定时出现；选择保留任务栏后不会每次启动反复遮住工作区。
- 未保存过常驻偏好的新旧用户默认看见 76px 紧凑栏；明确关闭过的人保持关闭。
- 接管状态与引导完成状态彻底分离，任务栏异常安全恢复后也不会重新弹出首次引导。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
