# FocusPanel 0.10.75

这一版修复紧凑栏“开始”和“任务视图”点击无反应。

- 开始按钮优先向 Explorer 任务栏宿主发送 Windows 公开的开始菜单系统命令，不再完全依赖模拟 Windows 键。
- 原生开始命令不可用时仍安全回退 Windows 键，兼容 Explorer 重启期间的短暂状态。
- 开始和任务视图改为明确的点击入口，等待鼠标事件完成后再调用系统动作，避免系统表面刚打开就被同一次点击关闭。
- Win+Tab 被系统策略或权限阻止时会展开状态中心显示失败原因，不再表现为完全无反应。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
