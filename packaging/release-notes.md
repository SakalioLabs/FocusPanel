# FocusPanel 0.10.66

这一版把 Wi‑Fi 网络选择带进 Panel 状态中心。

- 点击“查找网络”后列出附近 Wi‑Fi，当前连接与强信号网络优先。
- Windows 已保存的网络可直接连接，不再必须展开 Win+A。
- 只有重新读取到真实 Connected 状态才报告成功。
- 未保存网络不读取密码，安全转入 Windows 快捷设置完成首次连接。
- 位置权限被拒绝时说明原因，并可直接打开 Windows 位置权限设置。
- 使用公开 Native Wi‑Fi API，不读取 Explorer 私有网络面板数据。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
