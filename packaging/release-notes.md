# FocusPanel 0.10.77

这一版修复切换桌面收纳分区闪退，以及闪退后桌面图标没有恢复。

- 分区菜单不再使用 `async void`，菜单完全关闭后才提交分类和刷新布局，避免 WPF 点击栈重入。
- 未处理异常发生时会按每个项目保存的原始属性恢复已收纳图标，而不只是打开 Explorer 的全局桌面图标开关。
- 被任务管理器强制结束或断电时，下次启动会根据崩溃会话标记自动补做恢复。
- “桌面收纳 → 修复工具”新增“紧急恢复全部图标”，可找回旧版本闪退后已经隐藏、但没有留下崩溃标记的桌面项目。
- 恢复只处理 FocusPanel 登记的属性模式项目，不移动文件；权限不足或项目丢失时保留“需要恢复”记录。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
