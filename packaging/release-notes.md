# FocusPanel 0.9.46

- 开始菜单、公共开始菜单、AppsFolder 和快捷方式身份改为后台索引，Panel 不再等待完整应用目录才响应。
- 搜索与固定项先显示名称和首字符占位，真实图标由独立 STA 队列加载，Shell 图标提供器缓慢时不会卡住输入。
- 搜索面板会明确显示“正在载入应用目录”或“没有找到匹配的应用”，不再以空白列表代替状态。
- 重复图标请求会合并，成功结果复用；退出时停止排队并抑制迟到更新。
- 新一轮目录刷新会可靠淘汰旧结果，避免慢线程稍后返回导致应用列表倒退或闪动。
- 新增慢目录、慢图标、退出与并发刷新测试，应用和测试项目保持 0 错误、0 警告。
