# FocusPanel 0.11.19

- 状态中心新增“托盘应用 · 显示隐藏图标”，可以直接打开 Windows 原生托盘应用抽屉。
- 紧凑栏状态按钮右键菜单也提供同一入口，不必展开工作区或恢复整条原生任务栏。
- 第三方托盘图标仍由原应用和 Explorer 管理，保留原有左键、右键菜单及实时状态。
- FocusPanel 不复制托盘图标、不读取 Explorer 进程内存，也不会为打开抽屉临时显示原任务栏。
- 找不到折叠按钮时会在状态中心显示明确原因，不会误点网络、音量、电池、时钟或输入法按钮。

升级前仍会恢复原生任务栏；现有 SQLite 数据、桌面文件路径、自定义分区和用户设置不会被删除。
