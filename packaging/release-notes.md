# FocusPanel 0.10.71

这一版修复 FocusPanel 自身入口被收纳以及安装路径被旧 C 盘记录锁定的问题。

- 自动收纳永久排除 FocusPanel 官方快捷方式和当前程序文件。
- 检测到旧版误收纳自身入口时恢复当前属性模式收纳集的原始属性。
- 混合整理在管理员授权完成前不会隐藏任何图标。
- UAC 取消或助手启动失败时整批保持原状。
- 损坏的旧安装记录不再决定默认安装目录。
- 系统盘旧版会优先推荐可用的非系统固定盘并执行迁移。
- Windows Installer 写错目录时自动尝试撤销，不把错误安装留在 C 盘。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
