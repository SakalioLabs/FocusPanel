# FocusPanel 0.10.79

这一版让独立 watchdog 在 Panel 异常退出后立即恢复任务栏和桌面图标，不再等待用户重新启动应用。

- 被任务管理器强制结束后，watchdog 立即恢复原任务栏与已收纳桌面图标。
- `Ctrl+Alt+Shift+F10` 紧急恢复同时处理任务栏和桌面，不留下不可访问的收纳项目。
- 正常退出不会恢复已收纳图标，也不会改变现有分区。
- 恢复失败会保留标记供下次启动重试；任务栏和桌面恢复互不阻断。
- 0.10.78 的自动旧事故恢复和分区切换纯元数据事务继续保留。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
