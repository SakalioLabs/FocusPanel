# FocusPanel 0.11.5

这一版让任务入口承担更直接、可发现的快速收集动作，不再要求用户记住统一搜索语法。

- 紧凑栏“任务”左键仍直接打开任务工作区，不改变已形成的使用习惯。
- 右键新增“快速添加到 Inbox…”，选择后立即打开输入界面并聚焦标题末尾。
- 输入标题按 Enter 即可保存到 Inbox，成功后继续使用既有 Toast 和任务数量刷新反馈。
- 搜索表面在快速收集模式下明确显示“快速添加到 Inbox”和操作说明，不把它伪装成普通应用搜索。
- 菜单打开、输入和提交期间继续复用既有临时交互锁，Panel 不会意外自动收起。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
