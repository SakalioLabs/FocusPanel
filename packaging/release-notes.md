# FocusPanel 0.11.60

- 应用与窗口总览现在直接内嵌在状态中心，不再跳到搜索浮层。
- 单窗口应用可直接启动或切换，多窗口可原位展开并逐个切换、关闭。
- 应用抽屉与紧凑栏复用同一应用身份、顺序和右键管理能力。
- 列表独立滚动并回收虚拟化，再次点击只收起当前详情。

- 仅保留 Windows 消息窗口、没有普通顶层窗口的后台应用现在也能进入 Panel 统一应用栏。
- 消息窗口、隐藏宿主与可见窗口按 AUMID/可执行路径合并，多进程应用不会重复堆图标。
- 后台项继续支持点击请求打开界面、固定、取消固定和拖动排序。
- 实现使用公开 `FindWindowEx(HWND_MESSAGE, …)` 与现有 WinEvent 快照，不轮询全部进程、不读取 Explorer 私有托盘数据。
- 枚举失败、重复句柄或单个受保护进程不会拖垮普通窗口管理；系统和辅助进程继续过滤。

升级前仍会恢复原生任务栏；现有 SQLite 数据、桌面文件路径、自定义分区和用户设置不会被删除。
