# FocusPanel 0.9.86

- 修复桌面文件右键菜单在虚拟化、滚动复用或直接右键未选中项目后可能继续引用旧文件的问题。
- 每个可视文件卡片现在获得独立菜单实例；菜单 DataContext 始终绑定当前 `PlacementTarget`，不会跨卡片保留陈旧状态。
- 右键菜单打开时同步选中当前文件，“移动到”“收纳到面板”和“恢复到桌面”始终作用于用户刚刚右键的项目。
- 桌面文件菜单显式使用 FocusPanel Fluent 主题，深色模式不再依赖独立 Popup 的隐式资源查找。
- 新增菜单实例隔离、当前目标、主题绑定契约与真实 WPF UI 冒烟；506 项测试通过。
