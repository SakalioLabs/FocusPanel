# FocusPanel 0.10.65

这一版继续让 Panel 在原地完成任务栏需要展开快捷设置的高频无线操作。

- 状态中心新增 Wi‑Fi 与蓝牙直接开关，不再必须先展开 Win+A。
- 第一次主动切换时才请求 Windows 权限，本次会话只请求一次。
- 系统接受请求后继续读取最终硬件状态，不把“已提交”假装成“已成功”。
- 飞行模式、硬件开关、驱动、组织策略或权限阻止时显示具体原因。
- 多无线适配器按类型聚合并串行切换，保留快捷设置作为公开兜底。
- 使用 Windows 公开 Radio API，不读取 Explorer 私有托盘数据。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
