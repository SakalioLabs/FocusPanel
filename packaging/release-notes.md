# FocusPanel 0.10.72

这一版修复公共桌面快捷方式未收纳和紧凑栏按钮无法可靠开关的问题。

- Paint.NET 等公共桌面快捷方式不再被模糊当成 FocusPanel 自身入口。
- 后台发现公共桌面项目后显示明确的“授权收纳”按钮。
- 点击后整批只请求一次管理员授权；取消时图标保持原状。
- 已经存在的公共桌面项目也能进入待授权列表。
- 搜索、Focus 中心、状态中心和时间入口第一次点击即可展开并打开。
- 再次点击同一入口会直接收起整个侧栏。
- 设置与电源子表面也遵循所属入口的第二次点击收起语义。

升级前仍会恢复原生任务栏，现有 SQLite 数据、桌面文件与用户设置保持不变。
