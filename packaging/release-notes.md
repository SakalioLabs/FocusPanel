# FocusPanel 0.9.91

- 任务标题、状态和自定义字段的连续编辑改为 180ms 合并保存，同一项目的短时间变化只写入一次。
- 所有任务查询、添加、更新和删除通过同一串行闸门访问 EF Core DbContext，避免“同一上下文开始了第二个操作”异常。
- 编辑期间再次变化会保留一个尾随保存；不同任务按首次变化顺序持久化，单项失败不会阻断后续任务。
- 页面切换前排空旧任务的待保存内容；删除前取消排队更新，删除失败会恢复监听并保留界面项目。
- 快速连续进入不同项目时只接受最后一次加载结果，旧查询不会反向覆盖当前任务范围。
- 退出时先停止接收变化、排空保存队列并等待数据库空闲，再释放上下文，降低末次输入丢失和退出竞态。
- Release 构建 0 错误、0 警告，全量 529 项测试和界面冒烟通过。
