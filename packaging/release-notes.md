# FocusPanel 0.9.85

- 修复统一应用栏多窗口列表在深色主题下退回 WPF 默认浅色弹层、导致浅色文字几乎不可见的问题。
- 运行时创建的弹层、菜单项、子菜单和分隔线现在显式绑定 FocusPanel Fluent 主题；切换深浅色后继续使用动态画刷。
- 紧凑栏逻辑顺序统一为“开始、搜索、应用列表、任务视图、Focus 中心、状态中心、时间”，固定入口不再被应用列表打散。
- 下拉选择展开期间通过真实 `IsDropDownOpen` 状态保持 Panel 展开；鼠标移入独立 Popup 或键盘选项时不会提前自动收起。
- 新增菜单主题、六入口顺序、下拉交互锁和瞬态表面策略测试；505 项测试通过。
