# FocusPanel 0.11.57

- 应用触发 Windows 系统警报时，统一应用栏会显示琥珀色注意徽标和明确状态，不再依赖原生任务栏闪烁。
- 完整窗口总览同步标出具体的注意窗口；滚出可视区域的应用会自动露出一次，但不会改变固定顺序。
- 应用或同组窗口成为前台、窗口关闭、跟踪停止或应用退出时，注意状态立即清除。
- 实现复用公开 `EVENT_SYSTEM_ALERT` 与现有 WinEvent 快照，不轮询进程、不读取 Explorer，也不操作原生任务栏。
- 徽标使用纯圆形单层表面和统一主题颜色，没有新增矩形/圆角嵌套或硬编码边框。

升级前仍会恢复原生任务栏；现有 SQLite 数据、桌面文件路径、自定义分区和用户设置不会被删除。
