# FocusPanel 0.10.13

- AI 工作区打开时异步读取凭据状态与模型，不再同步等待 SQLite。
- API Key 解密、配置保存和清除通过后台闸门严格串行。
- 保存直接返回数据库已提交状态，避免 UI 线程额外查询。
- 保持既有 AppConfig 数据与当前 Windows 用户 DPAPI 密文兼容。
- 配置或凭据读取失败会显示明确错误且不会调用 API，迟到结果不会更新已释放页面。
- 修复偏移主屏和混合 DPI 双屏下 Panel 展开到屏幕夹缝的问题。
- Panel 动画与 3px 指示条统一使用主屏物理坐标，显示设置变化后立即重算。
- 新增带目录选择的 MSI；EXE 继续支持默认一键安装与 `--installto` 参数。
