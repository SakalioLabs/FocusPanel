# FocusPanel 0.11.56

- 没有可见窗口、但仍拥有隐藏顶层宿主的用户应用现在会进入 Panel 中部统一任务栏。
- 后台应用按 AppUserModelID 或可执行路径去重，多进程只显示一次，并保持稳定排序与固定能力。
- 后台项显示独立状态圆点；左键通过可靠启动目标请求应用打开界面，右键可以固定或启动新实例。
- 识别复用现有窗口事件快照，不轮询全部进程，不读取 Explorer 私有托盘数据，也不会弹出原生隐藏图标抽屉。
- 系统、跨会话、崩溃辅助进程和 FocusPanel 自身不会混入应用栏。

升级前仍会恢复原生任务栏；现有 SQLite 数据、桌面文件路径、自定义分区和用户设置不会被删除。
